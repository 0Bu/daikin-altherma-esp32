WiFi configuration

SSID must be 32 characters or less

Password must be empty (open network) or between 8 and 63 characters

SSID is required. If connection to the new network fails, the device rolls back to the old WiFi settings.

MQTT broker

Enter host:port — e.g. 192.168.1.10:1883 — or mqtts://host:8883 for TLS

Credentials require a TLS broker — use an mqtts:// URL (e.g. mqtts://host:8883). Empty host disables MQTT.

Syslog server

IP address or hostname and port of the Syslog server. Empty host disables Syslog.

NTP server

Hostname or IP of the NTP server the device syncs its clock from. Empty resets to the firmware default.

Board hardware

Holding the reset button for 5 seconds ERASES all stored settings (WiFi, MQTT, Syslog/NTP) and reboots into the setup portal — the LED flashes red while it is armed, then turns solid white while erasing. Leave the button on "None" unless one is actually wired: an unconnected pin can float and trigger it.
