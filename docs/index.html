daikin-altherma-esp32

Install the firmware

Flash your ESP32-S3 over USB straight from this page. Needs a desktop browser with Web Serial — Chrome or Edge.

!
This browser lacks Web Serial support — use Chrome or Edge on a desktop. Serial access was blocked — allow it and retry.

ESP32-S3 only · full flash (erases the device's existing configuration)

After flashing
  1. Join the WiFi network daikin-altherma-esp32-setup. The captive portal opens by itself — or visit 192.168.4.1 — and asks for your home WiFi.
  2. Once it reboots onto your network, open http://daikin-altherma-esp32.local. That dashboard is the whole app: the heat-pump model is detected automatically, and MQTT, syslog and NTP are set from the Connections tile.
  3. Wire the board to the heat pump's X10A service port — breaker off. See wiring.
