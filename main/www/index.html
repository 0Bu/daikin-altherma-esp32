WiFi configuration

SSID must be 32 characters or less

Password must be empty (open network) or between 8 and 63 characters

Enter the WiFi network name. If the device cannot connect, it restores the previous WiFi settings automatically.

MQTT broker

Enter host:port — e.g. 192.168.1.10:1883 — or mqtts://host:8883 for TLS

One base topic per device. A second board on this broker needs its own, or the two share their topics, their metrics and their Home Assistant device. Changing it renames this installation in Home Assistant and leaves the old retained topics behind on the broker.

A username or password requires an encrypted TLS connection (mqtts://, for example mqtts://host:8883). Leave the host empty to disable MQTT.

Syslog server

NTP server

Enter the hostname or IP address of the time server. Leave the field empty to use the firmware default.

Modbus

Search runs only when you press Search and fills the address field when a HomeHub answers. Save the result or enter an address manually. An empty address disables HomeHub completely: no search at boot and no requests. Port defaults to 502, unit id to 1. This dialog configures the data source only; it exposes no heat-pump control.

Board hardware
Outdoor sensor

AtomS3 Lite: use two offered pins — the case header carries GPIO5–GPIO8 and GPIO38. The Grove port (GPIO2/1) appears only while the X10A link is not on it: one pad cannot carry both the serial link and the I2C bus. GPIO39 is unavailable for ENV III.
